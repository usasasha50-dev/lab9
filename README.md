### Завдання 1: Модифікація однозв'язного списку цілих чисел
Для реалізації однозв'язного списку використано стандартний контейнер `std::forward_list<int>` із бібліотеки `<forward_list>`. 

Програма виконує такі етапи:
1. Заповнює список цілими числами.
2. Здійснює прохід по списку з метою пошуку значення останнього парного елемента.
3. Формує новий список-результат, де після кожного непарного елемента додатково вставляється знайдений парний елемент.

#### Лістинг програми (Завдання 1):
```cpp
#include <iostream>
#include <forward_list>

using namespace std;

int main() {
    forward_list<int> intList;
    
    intList.push_front(7);
    intList.push_front(6);
    intList.push_front(5);
    intList.push_front(4);
    intList.push_front(3);

    cout << "Початковий список цілих чисел: ";
    for (int n : intList) {
        cout << n << " ";
    }
    cout << endl;

    int lastEven = -1;
    bool hasEven = false;
    for (int n : intList) {
        if (n % 2 == 0) {
            lastEven = n;
            hasEven = true;
        }
    }

    forward_list<int> finalResult;
    auto prevIt = finalResult.before_begin();
    
    for (int n : intList) {
        prevIt = finalResult.insert_after(prevIt, n);
        if (n % 2 != 0 && hasEven) {
            prevIt = finalResult.insert_after(prevIt, lastEven);
        }
    }

    if (hasEven) {
        cout << "Останній парний елемент: " << lastEven << endl;
    } else {
        cout << "Парних елементів у списку немає." << endl;
    }

    cout << "Список після вставки: ";
    for (int n : finalResult) {
        cout << n << " ";
    }
    cout << endl;

    return 0;
}
```

### Завдання 2: Сортування списку дат у хронологічному порядку
Для розв'язання цього завдання використано стандартний вектор рядків `std::vector<std::string>` та алгоритм `std::sort`. Завдяки використанню стандарту форматування дат **`РРРР-ММ-ДД`** (ISO 8601), звичайне лексикографічне сортування рядків коректно забезпечує хронологічний порядок.

#### Лістинг програми (Завдання 2):
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

int main() {
    
    vector<string> dateList = {
        "2026-05-14",
        "2023-11-02",
        "2025-01-15",
        "2024-08-20",
        "2022-12-31"
    };

    cout << "Початковий список дат: " << endl;
    for (const string& date : dateList) {
        cout << date << "   ";
    }
    cout << endl << endl;

    sort(dateList.begin(), dateList.end());

    cout << "Список дат після сортування (у хронологічному порядку): " << endl;
    for (const string& date : dateList) {
        cout << date << "   ";
    }
    cout << endl;

    return 0;
}
```
